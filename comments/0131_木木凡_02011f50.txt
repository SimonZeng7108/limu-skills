评论区有不少关于 Agent 开发相关的问题，整理如下：
Code Agent 与程序员能力
有网友问"在 code agent 普遍落地的时候，对于程序员来说最重要的技能是什么"，李沐回复是 Tech Leader 级别的能力 ，基础代码实现、review、运行都被 AI 干掉了，但系统思维、架构设计、问题分解这些远不止于此。
一位 10 年 + backend 程序员问"现在转 AI Agent 还来得及吗，怎么快速有效地转"，求学习路径推荐。
有网友提出"编程不需要深度学了，只要学到能看懂代码就好了"，认为产品思维、描述能力、审美能力更重要。
Agent 框架与工具
有人请教"关于 Agent 的使用，比如 Codex 或者 Harness，完成基础安装后还需要了解/设置哪些"。
有网友讨论"从 OpenClaw 爆火到 Harness 逐渐成为 Agent 重要框架，下一个可能颠覆 LLM 应用层的技术框架会是什么"。
一位网友分享了自己做的"Agent Harness 方面的小项目"，在赶 ICLR 时想到的工作，已有相关代码。
Agent 研究方向与趋势
有人问"目前最前沿的 lab 在具身上会押注什么路线，是做通用大脑还是走 Agent 路线"。
有网友讨论"Agent 框架是否真有那么大不可替代的价值，本质就是一层 Agent 编排底座"。
有人问"Agent 出现之后论文数量激增，初学者怎样把握领域发展趋势、找到研究方向和创新点"。
一位做 AI 安全方向的网友提到自己做了很久"target on agent 的以 prompt 为主的攻防策略"，问 AI Sec 方向怎么看。
Agent 与职业/学习
有人问"目前学的方向是 Agent，硕士加博士要四年，四年后 Agent 还值得去学吗"。
有网友说"学生应该当成 independent researcher，能带着 Agent 独立完成工作"。
一位创业者说"用 AI 搭建了所有工作所需的东西，现在更重要的是产品思维、描述能力、审美的能力"。
总体来说，评论区对 Agent 的讨论集中在三个层面： 技术框架层 （Harness、Codex 等工具的使用与演进）、 能力定位层 （程序员在 Agent 时代该培养什么能力）、 研究方向层 （Agent 相关课题怎么选、有没有前途）。
