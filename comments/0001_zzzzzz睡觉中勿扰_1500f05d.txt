回复: @像小狗一样欢乐
李沐老师说的"tech leader能力"，结合评论区的讨论，主要指的不只是写代码，而是更高层面的几件事：
架构与系统设计：决定系统怎么拆、模块怎么设计、技术选型怎么做，这些是 code agent 目前很难替代的。
技术判断力：能判断什么方案值得做、什么技术该投入、什么该直接砍掉，本质上是对"做什么"和"不做什么"的决策能力。
业务理解与需求洞察：评论区也有人提到，洞悉需求、理解业务背后的赚钱逻辑，比单纯实现代码更重要。tech leader 需要把业务问题翻译成技术问题。
团队与协作：包括 code review 的质量把控、指导他人、跨团队沟通，这些"人"的工作也是 agent 替代不了的。
问题分解与系统工程能力：评论区有人分享用 vibe coding 时意识到，有系统思维之后可以不关心细节、一次性解决问题——这种把大问题拆成可执行小问题的能力，正是 tech leader 的核心。
简单说，李沐的意思大概是：代码实现这件事会被 agent 大量接管，但"决定做什么、怎么做、怎么组织"这些事，仍然需要人来做，而且会越来越重要。
